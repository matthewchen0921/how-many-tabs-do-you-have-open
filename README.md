137 — one number, digits only: the count of open browser tabs. Far above the dozen most people admit to, yet not a round number picked to shock; a real count is never round. It reads as counted, late at night, one tab at a time: forty half-read papers, a dozen half-written replies, and a tab bar that long ago gave up showing titles. The number is invented, not a real count. A small honest number like 12 reads as tidy and forgettable, a round 100 reads as guessed, and a huge 9999 reads as a joke — 137 reads as lived in.
